## Lifecycle input that stays

A future installer must be able to ask Core for a decision without sending `UserPromptSubmit`, `hookSpecificOutput`, or a Codex payload, and without opening SQLite itself. The retained input is the one the current functions already use internally:

- kind: `session_start`, `task_prompt`, `compaction`, or `ignore`
- `cwd`, `session_id`, and a bounded prompt
- the existing compact-resume signal currently read from `source`
- optional provenance that cannot choose the namespace

Core still resolves the project, selects local or configured remote authority, classifies the task, suppresses an exact repeated prompt, recalls at most once, and distinguishes no-hit from error and stale conflict. Capture continues to use `write_side_capture.capture_at_boundary` with the existing visible-artifact schema. Remote authority must keep blocking the local-only capture path.
